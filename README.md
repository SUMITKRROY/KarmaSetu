# KarmaSetu

KarmaSetu is a comprehensive Flutter application designed to streamline employee management and workflow approvals. The application is divided into two main modules tailored for specific user roles: the **Employee** module and the **Approver** (Management) module.

## Features

### 1. Employee Portal
The Employee section provides a seamless experience for staff to manage their daily work requirements:
- **Leave Management:** Employees can easily submit leave requests, track the status of their pending requests, and view their leave history.
- **Profile Management:** Quick access to personal information and professional details.
- **Notifications:** Receive updates on leave approvals or rejections in real-time.

### 2. Approver/Management Portal
The Approver section is designed for managers and HR personnel to efficiently handle employee requests:
- **Leave Approvals:** A dedicated dashboard to view, approve, or reject pending employee leave requests.
- **Request Tracking:** Keep track of all processed requests and manage team availability effectively.

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio / VS Code

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd KarmaSetu
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
